# Resume Directory

Place your resume PDF file here with the name: `Honglay_Rose_Lim_Resume.pdf`

The resume download functionality is configured to look for:
- File path: `/resume/Honglay_Rose_Lim_Resume.pdf`
- Download name: `Honglay_Rose_Lim_Resume.pdf`

## To update the resume:

1. Replace the PDF file in this directory
2. If you want to change the filename, update the paths in:
   - `/components/Hero.tsx` (downloadResume function)
   - `/components/Navigation.tsx` (downloadResume function)

## Current resume button locations:

1. **Hero section**: Prominent "Download Resume" button alongside "Get In Touch"
2. **Navigation bar**: "Resume" link in the main navigation (desktop)
3. **Mobile menu**: "Download Resume" option in the mobile navigation menu
